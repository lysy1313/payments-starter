# Backend — стартовый каркас

Node.js 24 + TypeScript + Express. Установку выполняйте из корня архива: `npm ci`.

Из корня проекта:

```sh
npm run dev:backend
```

Проверка в браузере: http://localhost:3001/api/health

Настройка порта необязательна. При необходимости скопируйте `.env.example` в `.env` внутри `backend` и измените `PORT`.

| Файл / папка | Для чего |
|---|---|
| `src/app.ts` | Сборка приложения и подключение маршрутов |
| `src/dev.ts` | Локальный запуск сервера |
| `src/config.ts` | Настройки |
| `src/routes/health.ts` | Единственный готовый маршрут: проверка запуска |
| `src/controllers/` | Будущие обработчики HTTP-запросов |
| `src/services/` | Будущая бизнес-логика |
| `src/db/` | Будущая схема и подключение PostgreSQL |

Папки для будущей логики пустые. Здесь нет заказов, таблиц, платежей, webhook, Stripe, PayPal, подключения БД или готовых решений учебных задач.

`app.ts` экспортирует Express-приложение отдельно от локального `listen`, что позволяет позже использовать сервер на Vercel. Перед публичной публикацией настроим окружение в отдельном уроке.

При добавлении webhook потребуется проверять подпись по исходному телу запроса. Порядок middleware в `app.ts` настроим в соответствующем уроке: общий `express.json()` нельзя бездумно ставить перед маршрутом, которому нужен raw body.

Проверка типов: `npm run typecheck --workspace backend` из корня. Сборка: `npm run build:backend`. После сборки локальный запуск: `npm run start --workspace backend`.
