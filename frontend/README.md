# Frontend — готовый интерфейс

React + TypeScript + Vite. Не обращается к backend или платёжным системам. Шрифт Inter поставляется вместе с проектом, без Google Fonts и сетевой загрузки с чужого домена.

Из корня проекта после `npm ci`:

```sh
npm run dev:frontend
```

Откройте http://localhost:5173. Backend для этого не нужен.

Готовые экраны:

- **Покупка:** разовый доступ или подписка, выбор Stripe/PayPal, количество и сумма в демопримере.
- **Предпросмотр:** экраны успешной оплаты, ошибки и ожидания.
- **Мои платежи:** статичная история, поиск, фильтр статуса, детали и пустое состояние.
- **Подписка:** план и локальное включение/отключение автопродления.

Кнопка «Перейти к оплате» открывает только предпросмотр. Заказ и платёж не создаются. История не пополняется при показе успеха. При перезагрузке страницы локальные состояния сбрасываются.

| Где | Что менять позже |
|---|---|
| `src/data/demo.ts` | Демонстрационные планы и строки истории |
| `src/pages/PurchasePage.tsx` | Подключение создания заказа и checkout в будущем уроке |
| `src/pages/PaymentsPage.tsx` | Загрузка истории с сервера в будущем уроке |
| `src/pages/SubscriptionPage.tsx` | Подключение подписок в будущем уроке |
| `src/components/PaymentPreview.tsx` | Готовые экраны результатов для последующего подключения |
| `src/components/Dialog.tsx` | Общие модальные окна |
| `src/styles.css` | Стили и адаптивность |
| `src/api/` | Пустая папка под будущую работу с API |

Цена вычисляется в браузере исключительно для предпросмотра интерфейса. Когда подключим API, сервер будет самостоятельно определять цену и подтверждать результат оплаты. Эти типы и демоданные ещё не являются контрактом серверного API.

Навигация сейчас переключает экраны через React state, без роутера. Для размещения этого интерфейса на Vercel дополнительных SPA rewrites пока не требуется. Разделы `/success` и `/cancel` с реальными возвратами от платёжной системы добавим в соответствующем уроке.

Проверка типов: `npm run typecheck --workspace frontend`. Сборка: `npm run build:frontend`. Предпросмотр сборки: `npm run preview --workspace frontend`, порт 4173.
